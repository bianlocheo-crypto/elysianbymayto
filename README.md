# Elysian Private Estates · Mayto

*El privilegio de pertenecer.* Investor site for Rosea, Viridis and Caerulea: three single-storey villas on the hillside at Mayto, Jalisco, 700 m from the Pacific.

A static site with no build step: `index.html`, `plan.js` and `media/`. Deployed on Vercel.

- Computers play the widescreen walkthrough films (`media/<villa>/tour.mp4`).
- Phones play the native vertical films (`tour-phone-hevc.mp4`, or `tour-phone.mp4` where HEVC isn't supported).
